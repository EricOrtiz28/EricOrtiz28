## Proyectos Destacados

- [**Inyeccion-de-codigo** (Público)](https://github.com/EricOrtiz28/Inyeccion-de-codigo)
  - Implementación en C++ de tres técnicas de inyección de código en Windows: Classic DLL Injection, Thread Hijacking y Windows Hooking. Incluye los inyectores, las DLLs maliciosas de prueba y los procesos víctima para demostración.
  - Tecnologías utilizadas: C++, Windows API

- [**Analizador-Estatico-de-Memoria-de-Procesos-Activos** (Público)](https://github.com/EricOrtiz28/Analizador-Estatico-de-Memoria-de-Procesos-Activos)
  - Herramienta de análisis forense en C++ que escanea la memoria de procesos activos en Windows para identificar anomalías, regiones de memoria sospechosas y módulos cargados. Complementa el proyecto de inyección de código como contramedida defensiva.
  - Tecnologías utilizadas: C++, Windows API

- [**TSP-con-Algoritmos-geneticos-Android** (Público)](https://github.com/EricOrtiz28/TSP-con-Algoritmos-geneticos-Android)
  - Aplicación Android que resuelve el Problema del Viajante (TSP) mediante un algoritmo genético con selección, cruce y mutación, optimizando rutas entre ciudades con visualización interactiva en el dispositivo.
  - Tecnologías utilizadas: Kotlin, Android

- [**AppMovil_CurvaBezier** (Público)](https://github.com/EricOrtiz28/AppMovil_CurvaBezier)
  - App móvil en la que se pueden crear puntos de control y visualizar la curva de Bézier resultante en tiempo real con una interfaz táctil interactiva.
  - Tecnologías utilizadas: Kotlin, Android

- **BehaviorNet Analyzer** (Privado)
  - Sistema de detección en tiempo real de técnicas de inyección de código en Windows, basado en **Redes de Comportamiento** (una variante de las Redes de Petri). Monitorea procesos mediante polling asíncrono, detecta secuencias de eventos como asignación de memoria remota, creación de hilos remotos y carga de DLLs sospechosas, y confirma la inyección cuando la red alcanza un estado de aceptación. Implementado como un único ejecutable de C++17 con concurrencia multihilo.
  - Tecnologías utilizadas: C++17, Windows API (kernel32, psapi, ntdll), std::thread, std::mutex

- **Detección de personas en tiempo real — Android** (Privado)
  - Aplicación Android con dos modos de detección: captura de foto/galería y cámara en vivo con CameraX. Las imágenes se suben a Cloudinary, se envían a una API remota de reconocimiento y los resultados se guardan en Firebase Realtime Database. En el modo en vivo, se dibujan rectángulos y etiquetas sobre las personas detectadas en el preview de la cámara.
  - Tecnologías utilizadas: Kotlin, CameraX, Retrofit, Firebase, Cloudinary

- **Análisis en Macrodatos con Spark ML** (Privado)
  - Proyecto de Big Data que implementa 8 modelos de Machine Learning (4 de clasificación y 4 de regresión) con Apache Spark ML y Scala sobre un dataset real de consumo energético de Perú. Incluye Pipeline completo con StringIndexer, OneHotEncoder y VectorAssembler, Grid Search con CrossValidator de 3 folds, tablas comparativas de métricas y gráficas de pérdidas.
  - Tecnologías utilizadas: Scala, Apache Spark ML, Python (matplotlib)

- **Oración Intercesora — Backend** (Privado)
  - API REST para gestionar pedidos de oración con autenticación JWT, validación con Zod, ORM Prisma y base de datos PostgreSQL. Soporta roles (ADMIN/USER), relaciones many-to-many entre usuarios y pedidos, y arquitectura por capas (routes → services → repositories).
  - Tecnologías utilizadas: Express, TypeScript, Prisma, PostgreSQL, Zod, JWT, bcryptjs

- **SIGFARM — Sistema de Gestión de Farmacia** (Privado)
  - Sistema full-stack para la gestión de ventas, pagos y despacho en una farmacia. Frontend en Angular 18 con roles de usuario (vendedor, cajero, despachador) y backend en Spring Boot 3 con API REST versionada, Spring Data JPA y PostgreSQL.
  - Tecnologías utilizadas: Angular 18, Spring Boot 3, Java 17, PostgreSQL

- **UA UNI — Plataforma web + Chatbot** (Privado)
  - Plataforma web para Universitarios Adventistas de la UNI con recursos espirituales embebidos (Biblia, Escuela Sabática, Himnario), sección de directiva y un chatbot inteligente conectado a un backend propio con la API de Gemini. El chatbot soporta sesiones, formateo de respuestas, exportación del historial y manejo de errores.
  - Tecnologías utilizadas: HTML, CSS, JavaScript, Node.js, Express, Gemini API
